# Stream32 Player

Stream32 Player — экспериментальный MP3-плеер на ESP32 с TFT-дисплеем, SD-картой и Bluetooth A2DP.

**Текущий статус: `0.0.9-beta`**

Это публичная бета-версия. Основные функции уже работают, но прошивка всё ещё может изменяться и требует проверки на конкретной плате и Bluetooth-устройстве.

## Возможности

- воспроизведение MP3 с SD-карты;
- Bluetooth A2DP Source и сохранение выбранного устройства;
- автоматический переход между треками;
- библиотека треков и избранное;
- портретный интерфейс на TFT_eSPI;
- темы Classic Green, Blue, Purple, Amber и Rose;
- яркость и таймер блокировки экрана;
- настройки автозапуска после подключения Bluetooth.

## Требования

- ESP32-совместимая плата с TFT-дисплеем и XPT2046 Touch;
- SD-карта;
- Arduino IDE с пакетом ESP32 3.3.x;
- библиотеки `TFT_eSPI`, `XPT2046_Touchscreen`, `ESP32-A2DP` и `minimp3`.

## Подготовка SD-карты

Создай папку `/tracks` и помести туда MP3-файлы:

```text
/tracks/
  Linkin Park - Numb.mp3
  Daft Punk - Get Lucky.mp3
```

Формат `Artist - Title.mp3` рекомендуется для корректного отображения названия.

## Установка

1. Настрой `TFT_eSPI` под свою плату и дисплей.
2. Установи зависимости через Library Manager или вручную.
3. Открой `PlayerV5.ino` в Arduino IDE.
4. Выбери свою ESP32-плату и загрузи скетч.
5. Вставь SD-карту и выбери Bluetooth-устройство через Settings → Bluetooth.

## Важные замечания

Проект рассчитан на портретную ориентацию дисплея 240×320 и текущую распиновку платы автора. Для другой платы могут потребоваться изменения пинов SD, Touch и подсветки.

Wi-Fi-загрузчик в beta-версии отключён.
